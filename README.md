# FB工具箱发布

本仓库保存 Windows 发布包和在线更新清单。

## FB投放版

[下载 2.2.0.212](https://github.com/GaoLiJ/facebook-onboarding-releases/releases/tag/ads-reports-v2.2.0.212)

首次接入在线更新，请下载 **FB-toolbox-ads-reports-2.2.0.212-win-x64.zip**，解压后运行 **FB工具箱.exe**。

此后工具箱可后台下载新版，在任务结束后提示，由用户点击重启工具箱生效。浏览器保持打开。
支持增量下载，条件不满足时自动使用完整包。名称含 `.delta.zip` 的附件供更新器使用，手动安装请选择完整 ZIP。

## 历史版本

[查看全部发布版本](https://github.com/GaoLiJ/facebook-onboarding-releases/releases)

历史发布保留独立的下载附件。原有 [Facebook 开户自动化 v2.0.4](https://github.com/GaoLiJ/facebook-onboarding-releases/releases/tag/v2.0.4) 仍可下载。

投放版、开户版使用各自的更新频道，按产品选择发布包。
